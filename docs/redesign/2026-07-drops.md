# Redesign 2026-07 — what we dropped, merged, and deferred

The record of everything removed or demoted in the July 2026 restructure (branch
`feat/redesign-2026-07`), per the feature audit (`docs/research/feature-audit-2026-07.md`).
Rule of thumb applied: **drop presentation surfaces, never data or backend capability.**

## Dropped outright (code deleted)

| What | Was | Why |
|---|---|---|
| **TickerStrip** home widget | Scrolling symbol strip at the top of Home | Duplicated Today's Watch with less context; ate the most valuable pixels on the page |
| **BullsFeed page** (`/bulls` route + nav tab) | Standalone feed of automated desk notes with beat filter chips | Merged into Home as the 🐂 Desks filter chip; `/bulls` redirects to `/?feed=desks` so old links and FB posts keep working. **Lost with it:** per-beat filter chips — per-desk streams still exist on desk profiles |

## Merged (feature survives inside another surface)

| What | Where it went |
|---|---|
| **EarningsWeek on Home** | Markets page (already there); earnings dates also reach users as alerts now |
| **Scanner** | Renamed **Ideas**, promoted to nav slot 2; `/scanner` redirects |
| **Symbol "Feed" + "Bulls" tabs** | One **Community** tab — the per-symbol posts feed always interleaved user posts and desk notes anyway |
| **Symbol "Fundamentals" + "Earnings" tabs** | One **Financials** tab (fundamentals panel + earnings/dividend history) |
| **DigestPanel + ExplainCard on Symbol Overview** | Removed from Overview; **Plain Read is the one narrative voice**. The `/digest` and `/explainer` API endpoints still exist and still work — nothing calls them from Overview anymore (candidates for reuse in AI summaries later; if still unused by ~Oct 2026, delete the frontend components) |
| **PulseGauges + Technicals on Symbol Overview** | Moved behind the **Lens** tab as the deep-dive layer |

## Demoted (still exists, different role)

| What | New role |
|---|---|
| **Markets page** | Reference browser, not a discovery competitor — Ideas is the front door for "what should I look at?" |
| **ScreenExplore** (`/markets/:key`) | Kept as Markets' internal drill-down (it already navigated as one). Screen titles were verified already human-language EN+BN — the audit's "Momentum 12-1" jargon existed only in internal keys |
| **Watchlist page** (`/watchlist`) | Kept but no longer in primary nav — Home's My Stocks widget and Portfolio cover the daily need |

## Frontend components now orphaned (deleted vs kept)

- Deleted: `TickerStrip.tsx`, `BullsFeed.tsx`
- Kept (still imported): `EarningsWeek.tsx` (Markets), `DigestPanel.tsx`, `ExplainCard.tsx`
  (unimported as of this redesign — flagged for deletion after one quarter if nothing readopts them)

## Deferred (wanted, not built — needs work we shouldn't rush)

| What | Why deferred | Prerequisite |
|---|---|---|
| **Block-trade ingestion + surfacing** | **Investigated 2026-07-03: dsebd.org publishes NO per-scrip block-trade list** — only a daily aggregate ("N scrips traded in Block") on market-statistics.php. Per-scrip data exists on LankaBD (a competitor brokerage's site — ToS/strategic risk to scrape) | Decision needed: LankaBD scrape vs licensed DSE feed vs skip. Sponsor Selling board (shipped) covers the adjacent insider-flow story from official data |
| **Going-concern / financial-statement-submission red-flag inputs** | Same — new scrape targets | Same |
| **Earnings-reminder alerts** ("results in 13 days") | Needs a "days-until" scheduler pass over announcements, not just event fan-out | Small worker cron job |
| **Push notifications** | PWA push infra (service-worker + VAPID + permission UX) | In-app inbox shipped first by design |
| **Quiz badges** | Streaks + points shipped; badge definitions/art are product work | Decide badge taxonomy |
| **Rising-sponsor streaks** | Only falling streaks fire today (the caution case) | Decide if positive streaks earn a note (risk: reads as endorsement) |

## What did NOT change

All backend analytics, screener boards, agents, moderation, Facebook publishing, admin, i18n —
untouched. Every dropped surface's underlying endpoint still responds; this was a hierarchy
change, not a capability change.
